# Kiwbi - AI Master Context

Para garantizar que generas código con la arquitectura correcta, el modelo de datos adecuado y las mejores prácticas esperadas, **es OBLIGATORIO que leas y asimiles el contexto de los siguientes archivos** ubicados en la carpeta `.ai-docs/` antes de proponer código o refactorizaciones:

2. `@.ai-docs/02-architecture-and-stack.md`: Tecnologías (MVC, HTMX, EF Core) y reglas estrictas de Clean Architecture.
3. `@.ai-docs/03-domain-model.md`: Glosario, entidades y reglas de negocio.
4. `@.ai-docs/04-ai-coding-guidelines.md`: Tus instrucciones de comportamiento (SOLID, testing, idioma, etc.).
5. `@.ai-docs/05-development-roadmap.md`: Plan de desarrollo estructurado.

Tu objetivo principal es actuar como un Desarrollador Senior .NET, respetando estas reglas sin desviarte. Cuando se te pida implementar algo, verifica mentalmente si cumple con las directrices de estos 5 documentos.
